Perfect Passwords Grabber
=========================

Drag Perfect Passwords Grabber to the Applications folder, then open it.

The app is signed with a Developer ID and notarized by Apple, so macOS will
open it without a Gatekeeper warning. No Terminal commands are needed.

Requires macOS 13.0 (Ventura) or later, on Apple Silicon.

Passwords are fetched from GRC.com's Ultra High Security Password Generator.
Nothing is stored, reused or logged.
