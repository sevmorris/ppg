**Changed**
- **Perfect Passwords Grabber now requires macOS 15 (Sequoia) or later.** It ran on macOS 13 and 14 until now. GitHub no longer offers macOS 14 to test on, so nothing could check the app there any more.
- **Check for Updates won't offer a version this Mac can't run.** From this release on, every release says which macOS it needs, and the update check reads it. When a newer version needs a newer macOS than this Mac has, Check for Updates… says which macOS that is instead of offering the download, and the check at launch says nothing.

There are no changes to how passwords are fetched, displayed or copied.

**Developer**
- `Package.swift` declares `.macOS("15.0")` (`.v15` would need swift-tools-version 6.0 and Swift 6 language mode), and the app's `NSApp.activate()` calls lose their macOS 13 fallback.
- CI tests on `macos-26` and GitHub's `xcode-27` runner (macOS 27, Xcode 27.0) as well as `macos-15`.
