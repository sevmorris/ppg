**Changed**
- **A new icon.** Perfect Passwords Grabber now looks like the other apps it sits beside: an orange asterisk, the character a password field shows in place of each letter, on the same blue as WaxOnWaxOff, ClipHack, FilmStrip and KeyVault. It is also drawn to Apple's icon grid, so it no longer looks larger than the icons around it in the Dock.

There are no changes to how passwords are fetched, displayed or copied.

**Developer**
- `tools/icon/make-appicon.py` generates `assets/AppIcon.icns` (Pillow and `iconutil`), and its output is the same from run to run. `assets/icon-source.png`, the old artwork, is gone.
- `release.sh` no longer prunes the newest release for an older minimum macOS, since that is the last version those Macs can run.
